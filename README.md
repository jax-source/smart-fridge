# 智能冰箱 PWA 应用

🧊 管理冰箱食材，智能推荐菜谱

## 功能特点

- 📦 **食材管理** - 添加、编辑、删除食材，设置保质期
- 📖 **菜谱管理** - 录入个人菜谱，记录烹饪步骤
- 🎲 **智能推荐** - 根据现有食材随机推荐菜谱
- 📱 **移动端优化** - PWA 应用，可安装到手机

## 快速开始

### 本地开发

\`\`\`bash
npm install
npm run dev
\`\`\`

### 部署

\`\`\`bash
npm run build
\`\`\`

## 技术栈

- React 18
- TypeScript
- Vite
- TailwindCSS
- Zustand
- IndexedDB
- PWA
